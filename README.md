# depth – Dynamisches Teilungs‑, Kraft‑ und Axiom‑System

Dieses Repository enthält ein vollständig modulares depth‑Framework.  
Es bildet ein fraktales Kraft‑, Teilungs‑ und Axiom‑System ab, das aus  
Einleitung, Losleitung, Einteilung und Teilung besteht.

---

## 🚀 Pipeline (Hauptfluss)

Der depth‑Datenfluss besteht aus vier Kernmodulen:

1. **Einleitung** – Startimpuls  
2. **Losleitung** – Weitergabe des Impulses  
3. **Einteilung** – Auswahl der Achse  
4. **Teilung** – Ausführung der Achse  

Diese vier Module bilden die Basis des gesamten Systems.

---

## 🧩 Achsen (6‑Achsen‑Teilung)

Das depth‑System arbeitet mit sechs Achsen:

- **unter** → u.t.js  
- **über** → t.u.js  
- **tief** → UM.x.js  
- **y.x** → y.x.js  
- **x.y** → x.y.js  
- **q.t** → q.t.js  
- **t.q** → t,q,js  

Die Achsen werden durch die Einteilung dynamisch aktiviert.
